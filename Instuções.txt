1. Comando para transformar o vídeo em áudio usando o modo terminal:
C:\ffmpeg\bin\ffmpeg.exe -i nome do arquivo.webm -vn -acodec pcm_s16le -ar 16000 -ac 1 audiencia.wav

2. Comando para fazer a degravação simples do áudio:
python -m whisper audiencia.wav --language Portuguese --model base

3. Corrigir usando o VS conde:
python gerar_narrativa_lmstudio.py audiencia.txt -n "Nome do Depoente" -p testemunha

4. Se precisar mudar o modelo no futuro:
mudar a linha 8 MODELO_LM_STUDIO = "meta-llama-3.1-8b-instruct"

5. python transcricao_narrativa.py -n "João da Silva" -p testemunha
-n "Nome" Nome do depoente (obrigatório)
-p papel Papel: vítima, testemunha, informante, acusado (obrigatório)
-a arquivo.mp4 Nome específico do arquivo na pasta temp (opcional)
-w medium Modelo Whisper: tiny, base, small, medium, large (padrão: medium)
